# Theory Behind Splink: The Fellegi-Sunter Model and EM,  Estimation in Splink, and Extensions

This document explains how Splink estimates and applies the Fellegi-Sunter model of probabilistic record linkage. Fellegi and Sunter (1969) showed that the optimal rule for classifying a pair of records as a link or a non-link depends on the ratio between the probability of the observed agreement pattern among matching pairs and its probability among non-matching pairs. Splink (Linacre et al., 2022) is an open-source Python package that implements this model in SQL so that it can run on large datasets.

Sections 2 through 7 derive the model. They set out the notation, the conditional independence assumption, the posterior match probability and the expectation-maximization (EM) updates for the parameters. Section 8 describes how Splink departs from textbook EM. It estimates the prior from deterministic rules and the non-match parameters from random sampling, runs EM within blocks and adjusts for term frequency. The section ends with prediction. Section 9 describes three extensions I made for my applications, which are a sampling scheme for EM training when individuals have several ranked observations, parallel prediction, and one-to-one comparison enforcement. Appendix A proves that an EM update cannot decrease the likelihood. This paper considers Splink v4, so newer versions may differ in implementation.
